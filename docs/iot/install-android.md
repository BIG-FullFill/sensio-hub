# Sensio IoT Android Mobile Application

The **Sensio IoT Android App** provides a native mobile interface with spatial controls, push notifications, voice transcription, and secure offline-capable session caching.

---

## 2. Installation on Android Devices

1. Transfer the `.apk` file to your Android phone or tablet (or download directly in the mobile browser).
2. Open the downloaded file from your notifications or file manager.
3. If prompted, enable **"Install unknown apps"** for your browser or file manager in Android Settings.
4. Tap **Install** and open **Sensio IoT**.

---

## 3. Connecting to your Sensio Server

1. Open the Sensio app.
2. Enter your server URL (e.g. `https://iot.yourdomain.com` or local IP `http://192.168.1.50:3000`).
3. Enter your administrator or viewer account credentials.
4. Your sites, rooms, and devices will hydrate automatically.
