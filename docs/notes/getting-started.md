# Getting Started with Sensio Notes

Sensio Notes provides a privacy-first, markdown-native knowledge base with encrypted synchronization across devices.

---

## 1. Feature Highlights

- **Markdown Native**: Seamless WYSIWYG and code-first editing with bidirectional linking.
- **Sensio IoT Linking**: Reference smart spaces, rooms, and devices directly in meeting notes and automation blueprints.
- **End-to-End Encryption**: Secure synchronization between desktop, mobile, and your self-hosted server.
- **AI Summary & Organization**: Local embedding search and contextual summaries.

---

## 2. Status

Sensio Notes is currently in active development. Self-hosted server deployment definitions will be published in `deploy/notes/` upon initial release.
