# Sensio Notes Android Mobile Application

The **Sensio Notes Android App** provides a privacy-first, markdown-native knowledge base with encrypted synchronization, audio transcription notes, and seamless integration with your self-hosted Sensio ecosystem.

## 2. Installation on Android Devices

1. Transfer the `.apk` file to your Android phone, tablet, or POS system (or download directly in the mobile browser).
2. Open the downloaded file from your notifications or file manager.
3. If prompted, enable **"Install unknown apps"** for your browser or file manager in Android Settings.
4. Tap **Install** and open **Sensio Notes**.

---

## 3. Connecting to your Sensio Server

1. Open the Sensio Notes app.
2. Tap the Settings icon in the top header.
3. Enter your server URL (e.g. `http://100.99.88.53:8080`, `http://192.168.10.100:8080`, or your custom domain).
4. Tap **Apply** to synchronize your notes immediately.
